All production rules persist in `docs/production/`, not in chat history. **VIDEO DEFAULT:** full script first and locked, then storyboard, per-scene on-brand still images and prompts, mostly paired Midjourney start/end animations, real stills and clip capture URLs, Premiere directions. **Do not render a video or MP4 without an explicit owner request** (a request for a script, storyboard, images or transitions is not one). Keep lean sourced articles, TIP six-issue records, claim-driven independent QA and authorized publishing. Legacy Florida hard-coded timing and auto-render steps are superseded. Static site built by `build.py` (stdlib Python) with election pages from `elections.py`. Companion project: The Issues Party (TIP), a separate Next.js repo that holds candidate profiles and issue grades; LLF only reads and links to it.

## Rules that never change
- Scope: Governor, U.S. Senate, U.S. House. Neutral reporting; no win probabilities; no causal claims about spending or prices; no rankings or endorsements.
- R1 the first mention of a featured candidate links to their TIP profile; R2 every mentioned race links to that race; a grade is cited only from the profile that shows it; "not graded" is never zero.
- Reported numbers are attributed ("according to <outlet>") and never called audited. A search snippet is not reporting: open the article.
- The drafter does not check their own article (a different reviewer is recorded). Nothing is published, posted, uploaded, deployed, rendered or written to a production database without the owner's explicit authorization, recorded with `--authorization` in the workflow ledger.
- Finance data (FEC) is optional and never a gate. Story first, proof enough.
- Style: no Oxford comma ("first, second and third"). Plain, precise, no hype.
- Video (Lock v2.0, `docs/production/03_VIDEO_SKILL_AND_SHOT_CONTRACT.md`): assets only; script locked before scene art; timing follows the script (the Florida 18 x 5 layout is a historical example); real people are real licensed stills or real clips, never generated likenesses; exact data (names, numbers, polls, Kalshi, maps, TIP grades) is a deterministic overlay, never printed by Midjourney; every clip has an explicit rights status, `CLEARED` only with a written basis, and a public clip is not a permitted clip; the owner chooses and captures footage; AI visuals and the synthetic narrator are disclosed.
- When a data source cannot be read (for example the Illinois State Board of Elections site returning HTTP 403), record it in `docs/production/DATA_ACCESS_LIMITATIONS.md` and never present the result as complete or official.

## Windows notes
Use `PYTHONUTF8=1`; prefix `MSYS_NO_PATHCONV=1` when passing a URL path starting with `/` from Git Bash; stop the local server (`python -m http.server 8091` in `dist/`) before running `build.py`; write files that contain quotes with the editor tool, not shell heredocs.

## Do not
Overwrite an installed skill without reading it; start a state's production before the owner says so; render, export or commit a video file (`assets/video/*/source`, `selects`, `thumbs` and `captions` are git-ignored); download footage unless the owner explicitly asked for that clip and it is `CLEARED`; upload `release/looklearnfind-site.zip` (older build, overwrites the live robots.txt); store or print keys; re-run the removed FEC Schedule B pull; move or rewrite returned discovery material (for example `docs/illinois/`).
