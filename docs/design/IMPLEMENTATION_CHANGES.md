## 3. Behavior
- **Desktop (901px and up):** fixed 236px charcoal rail (original logo with the lit mode word, Look / Learn / Find, search, Browse, a contextual block, About links). The mast stays and is offset by the rail; its logo moves into the rail. One content canvas.
- **Mobile (900px and under):** fixed 64px bar (logo, modes, Explore) and an Explore sheet with search, Browse, Look, Find, About, Sign in and the same contextual block.
- **Modes by route** (matrix in the spec): LOOK for `/look/` and `/u/`, FIND for `/find/`, LEARN for `/learn/` and `/elections/`, none elsewhere.
- **Contextual block:** story state lens and recommendations (existing editorial logic and discovery data, unchanged); state picker (opens a hub) on political and election pages; "On this page" outline only from real `<h2 id>` headings; otherwise absent.
- **Global search:** the form submits to `/search/?q=` (which the search page already reads). `/` focuses it unless a field is focused.
- **Every page** (all 250, including account, admin, search, 404 and Florida's separate generator) gets the shell through the single page writer. The strict build and the tests enforce it.

## 5. Palette migration (what actually changed)
Teal `#145b5d` to blue `#28636c` (and `#0f4145` to `#173e47`); yellow `#dfca00` and `#e7d000` to `#f0d800`; mast `#1d1d1d` to `#1d1e20`; paper `#f5f2eb` to `#f8f6f0`; ink `#1c1d1b` to `#222326`; muted `#5d6a61` to `#646b70`; rule `#c9c4b9` to `#d7d3c9`; plus the cream and warm neighbors. About 46 CSS literals and 9 inline Python literals; all other colors route through tokens. The old green rail background image (`sidebar-politics.webp`) is no longer used with the shell on.

## 6. Rollback
Set `"global_shell": false` in `config.json` (or `LLF_GLOBAL_SHELL=0` for one build) to restore the previous layout: the rail on stories only, mast with logo elsewhere. The palette and the few layout fixes stay. Full revert: `git checkout` the changed files and delete the new ones. Neither was deployed, so the live site is unaffected.
