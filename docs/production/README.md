# docs/production: the LLF production lock (installed 2026-10-28)

This folder is the permanent home of **LLF Canonical Local Workflow & Skills Lock v2.0 (2026-10-24)**, installed into the existing repository (not a second repository, not an external folder). Session startup reads this folder through the root `CLAUDE.md` and `docs/election-build/INDEX.md`. The package was created in ChatGPT; this install is what makes it real. Files `00` to `07`, `ROOT_CLAUDE_POINTER.txt` and `templates/` are the package text, verbatim (the one exception: `templates/ASSETS.csv` has an added last column `aspect_ratio`, needed to check that paired transitions match). ## Precedence
The package says previous directions inconsistent with it are superseded. Applied as follows (details in `INSTALL_REPORT.md`):
1. Video is **assets only**: script (locked) → storyboard → scene visuals → paired start/end transitions → real-clip capture list → Premiere notes. **No MP4 ever without an explicit request for a rendered video.**
2. The fixed 18 x 5-second storyboard and its builder are the **Florida historical example**, fenced from other states.
3. One video entry point: `llf-video-director`. `llf-video-storyboard` is a legacy alias; `llf-footage-scout` is a sub-procedure and does not download by default.
4. Article workflow is unchanged and not downgraded: lean `STORY_BRIEF.md` and `CLAIMS.csv`, `llf-story-scout`, `llf-article-format`, `llf-factcheck-finalize`, `llf-election-render`, `llf-publication-qa`, strict build, owner authorization to publish.
5. Workflow stages: the canonical `production:<state>-<year>` lane (12 stages) and the separately authorized `render:<state>-<year>` lane are implemented in `tools/workflow/transitions.py`. The older `story:` and `video:` lanes stay valid for existing entries and map onto them.
6. Folders: `productions/<year>/<ST>/` (research, articles, graphics, visuals, clips, transitions, video, qa, release, logs). Work already produced elsewhere (Florida, the Illinois discovery in `docs/illinois/` and `data/elections/IL/`) is not moved.

## Sharing with ChatGPT
Cross-model skills are not installed in ChatGPT. Each project, hand it the portable knowledge center (`LLF_KNOWLEDGE_CENTER_<date>.zip`: this folder, the skills, `CLAUDE.md`, the index, runbook, publishing rules, schemas and the manifest) so it loads the same instructions.
