# LookLearnFind — Find Ledger handoff

Build the Find Ledger page from the **final v2 mockups** in this package. The desktop and phone PNGs are the visual references. The HTML files are static layout references with local asset paths that work when the ZIP is extracted with its folder structure intact. `LookLearnFind-find-ledger-proposal.md` defines the mechanics, copy, data distinctions, and launch scope.

## Files

- `llf_ledger/LookLearnFind-find-ledger-v2-desktop.png` — final desktop mockup.
- `llf_ledger/LookLearnFind-find-ledger-v2-mobile.png` — final phone mockup.
- `llf_ledger/ledger-v2.html` and `llf_ledger/ledger-v2-mobile.html` — static HTML/CSS layout references; these are not wired to live data or functional controls.
- `LookLearnFind-find-ledger-proposal.md` — functional and copy proposal.
- `llf_homepage/assets/` — the approved logo and image assets used by the mockup.
- `llf_homepage/LookLearnFind-homepage-preview.png` — homepage reference for brand consistency.

## Implementation priorities

1. Make the public index a fast, filterable **table/list**, with one 9:16 preview per row. The portrait ratio serves YouTube Shorts and Instagram Reels; do not turn the main index into wide video cards.
2. Keep title, human save note, topic, post kind, duration, platform, original creator, saver, and open/save actions visible without expanding a row. On phones, condense the same fields around the vertical thumbnail.
3. Use warm paper and very light alternating rows. Green belongs on buttons, links, and restrained accents. Keep the larger content surfaces light.
4. Preserve the approved `01` logo. Keep `L / 042` Ledger IDs separate from `SOURCE 01` footnotes in sourced Learn stories.
5. Treat screenshots' clip titles, creator handles, dates, and counts as **illustrative**, not published or verified content. The photos are visual stand-ins; use a real provider thumbnail or a clearly labeled fallback for actual posts. Do not represent these stock-like editorial images as frames from a real creator's video.
6. Use the proposal for private saves, public opt-in, profiles, following, chronology, submission review, canonical video deduplication, and links to Learn/real-world Find content.

The previous gallery-style mockup and the segmented PDF were rejected; this ZIP contains the revised table direction only.
